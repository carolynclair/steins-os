Welcome to the laboratory

Open applications with the Steins;OS menu at the top left. Network, volume and clock controls are at the top right. Use Settings Manager for display scaling, keyboard, power and accessibility. About Steins;OS in the menu summarises this system.

Six worldlines

The desktop has one number, the divergence, from 0 to 6. The whole number picks a world. Changing worlds changes the wallpaper, the terminal colours, the top bar and the desktop widget together.

The everyday terminal

Terminal in the menu opens an ordinary Bash shell. Its colours follow the current world. The prompt shows your user and computer, the folder, the Git branch when you are inside a repository, the exit code when a command fails and how long a command took when it ran for five seconds or more. Run steins-info for a short system summary.

The prompt replaces only Debian's standard prompt; a prompt you set in ~/.bashrc is kept. To keep Debian's prompt, add export STEINS_PROMPT=off to ~/.profile. STEINS_GREETING=off or an empty ~/.hushlogin file hides the greeting line. Font, cursor and scrollback are in the terminal's own Preferences and stay as you set them.

The ibm5100 terminal

Open a terminal and run ibm5100, a retro amber console. Useful commands:

  • HELP lists commands; LIST shows the six worlds in order; DIVERGENCE shows the meter.
  • SET 2.198306 sets the number directly (0 to 6).
  • DMAIL your message sends a D-Mail. The text decides how far the number moves, and the same text always gives the same shift.
  • Codes are typed on their own. Try CICADA, which selects Hinamizawa. More are out there; EXIT closes the link.

The same actions exist outside the console as steins-worldline set NUMBER and dmail "message". A D-Mail is fiction and local-only: it stays on this computer, nothing is sent, and no network is used.

Real or fiction

Decorative: the divergence number, worldline names, D-Mail and codes. They only choose colours and wallpaper.
Real: the CPU, memory, disk and uptime readings in the desktop widget and in System information.

The number is not a measurement of your computer, and nothing in this system predicts or alters real events.

The optional divergence meter

Search the menu for Divergence Meter for a small window of glowing digits that follows the current number. Enter opens ibm5100; Esc closes it. It does not start by itself. The desktop widget is the default readout, so start the meter only if you want both.

Saving, and reopening apps

On the live USB, changes disappear at shutdown. On an installed system your number is kept in your home folder and re-applied at login.

After a world change, apps that were already open keep their old accent colours. Close and reopen GTK applications to see the new accent. The panel, wallpaper, terminal and widget update immediately.

Prefer a fixed look? Choose another wallpaper in Desktop Settings, or hide the widget in Session and Startup → Application Autostart.

Install

Back up your files. Launch Install Steins;OS from the application menu while running the live USB. Review the destination disk carefully: partitioning can erase data. Choose region, keyboard, partitions and your personal account. After installation, shut down, remove the USB and boot the installed system. The installer is only offered from the live session.

Accounts

The live account is lab with Debian live's default password live, and passwordless administrative access for installation. The installer creates your personal account. Never treat the live session as a secured installation.

Updates and software

Debian security updates are enabled automatically. Use Synaptic, or run sudo apt update && sudo apt full-upgrade, and reboot after kernel updates. Packages and firmware come from Debian repositories. Steins;OS has no update service of its own yet, so its own files (theme, tools, artwork) are not updated separately.

Recovery and limitations

If graphics fail, use the safe graphics option in the boot menu. Compatibility with specific Wi-Fi, graphics, suspend and Secure Boot setups needs hardware testing and is not claimed. This is a development preview, not a production-certified release. Check your files are backed up before installing.
