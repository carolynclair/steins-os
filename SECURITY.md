# Security reporting

Steins;OS is an experimental distribution project. It has no production support guarantee or promised security response time. Debian supplies upstream package updates; that does not replace validation of Steins;OS integrations and releases.

Do not disclose passwords, tokens, private mail, disk images or personal logs in issues. For a suspected vulnerability, use GitHub's private vulnerability reporting option in this repository's Security tab if it is available. Otherwise, open a minimal issue asking the maintainer for a private reporting route, without exploit details or sensitive material.

For a vulnerability in an unchanged upstream component, report it through that project's security process as well. Identify the affected Steins;OS build, package versions and whether the issue concerns the live environment, installer or installed desktop. Reproduce destructive or installer behaviour only against disposable VM storage.
